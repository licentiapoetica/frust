# Built-in fonts

Shipped with f0ckm and offered in Settings → Website Font (see `server/src/fonts.rs`).

| Font | Files | Version | Copyright | License |
|---|---|---|---|---|
| Manrope | `Manrope-*.woff2` (ExtraLight 200 … ExtraBold 800) | 4.504 | Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope, now maintained at https://github.com/googlefonts/manrope) | SIL Open Font License 1.1, [`LICENSE-Manrope-OFL.txt`](LICENSE-Manrope-OFL.txt) |
| Hack | `Hack.woff` (Regular) | 3.003 | Copyright 2018 Source Foundry Authors (https://github.com/source-foundry/Hack); Bitstream Vera Sans Mono Copyright 2003 Bitstream, Inc.; DejaVu changes in the public domain | MIT License and Bitstream Vera License, [`LICENSE-Hack.md`](LICENSE-Hack.md) |

The Manrope files are subsets (Latin, 280 glyphs per weight) of the original release; the OFL allows
this, and Manrope has no Reserved Font Name. The license texts are the upstream ones: Manrope's from
the Google Fonts repository (`ofl/manrope/OFL.txt`), Hack's from its repository (`LICENSE.md`).
