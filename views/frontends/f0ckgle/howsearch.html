How Search works

F0ckgle doesn't crawl the web. It looks through the f0cks on {{ domain }}: their tags, titles, uploaders, favs, comments, sizes and ages. Type words to find tags, add operators to say exactly what you want, and mix them as wildly as you like.

Words Exact tags Not & or People The file Numbers Time Order Go wild

Words

Every word you type has to be part of one of a f0ck's tags. {{ ex("cat") }} finds cats, black cat and catgirl; {{ ex("black cat") }} finds f0cks with a tag containing black and a tag containing cat (or one tag with both). Upper and lower case don't matter, and neither do spaces, dashes and accents inside a word: {{ ex("blackcat") }} finds black cat too.

Results come 20 to a page, newest first. Within a page the best fits go to the top: a tag that is your first word, or starts with it, beats one that only has it in the middle. The Match under each result says how close it is.

Exact tags and wildcards

{{ op('"', 'tag"', "A whole tag, nothing more: no catgirl for \"cat\".", '"black cat"') }} {{ op("tag:", "name", "The same as quotes.", "tag:cat") }} {{ op("*", "", "Any text in a tag (the whole tag has to fit the pattern).", "cat*") }} {{ op("?", "", "Exactly one character.", "c?t") }}

Verbatim above the results makes every word exact. There, commas separate tags: {{ ex("black cat, funny", true) }} finds f0cks tagged exactly black cat and funny.

Leave out, or either

{{ op("-", "word", "Leaves out what the word (or any operator after the dash) finds.", "cat -dog") }} {{ op("OR", "", "Either one: a OR b, or a | b. Binds the terms next to it.", "cat OR dog") }}

Everything else is AND: {{ ex("cat OR dog funny") }} means (cat or dog) and funny.

People

{{ op("user:", "name", "Uploaded by them. Also from: and by:. Wildcards work in names.", "user:" ~ (session.user if (session and session.user) else "admin")) }} {{ op("fav:", "name", "In their favs (unless they keep their favs private).", "") }} {{ op("commenter:", "name", "They commented on it.", "") }} {{ op("tagger:", "name", "They gave it a tag.", "") }} {{ op("is:", "fav", "In your own favs.", "is:fav") }} {{ op("is:", "mine", "Your own uploads.", "is:mine") }}

On a site that hides who uploaded what, the people operators are left out.

The f0ck itself

{{ op("type:", "kind", "video, image, gif, audio or flash (also is:video and so on).", "type:gif") }} {{ op("ext:", "end", "The file ending.", "ext:webm") }} {{ op("rating:", "r", "sfw, nsfw, nsfl, or untagged (none of them).", "rating:sfw") }} {{ op("title:", "text", "The title contains the text; title:\"two words\" keeps them together.", "title:fail") }} {{ op("src:", "text", "The source, the address it came from.", "src:youtube") }} {{ op("hall:", "name", "In that hall.", "") }} {{ op("is:", "oc", "Original content. Also is:pinned, is:expiring, is:public, is:unlisted, is:private (your own).", "is:oc") }} {{ op("has:", "what", "has:title, has:src, has:comments, has:favs, has:tags, has:cover.", "has:comments") }} {{ op("related:", "f0ck", "Shares tags with that f0ck (its number or link name); the most shared first.", "") }}

Numbers

Give a number, or compare: >, >=, <, <=, or a range 10..50. Big numbers can be written 2k.

{{ op("views:", "n", "How often it was watched.", "views:>100") }} {{ op("favs:", "n", "How many favs it has.", "favs:>=2") }} {{ op("comments:", "n", "How many comments it has.", "comments:>0") }} {{ op("tags:", "n", "How many tags it has (the rating doesn't count).", "tags:<2") }} {{ op("duration:", "time", "Length in seconds, or 1m30s, 1:30, 2h.", "duration:>2m") }} {{ op("size:", "bytes", "File size: 500k, 10mb, 1gb.", "size:>10mb") }} {{ op("width:", "px", "Width, height: and height in pixels.", "width:>=1920") }} {{ op("id:", "n", "The f0ck's number.", "id:1..100") }}

Time

{{ op("year:", "2024", "Uploaded in that year; date: takes 2024-06 or 2024-06-15 too.", "") }} {{ op("after:", "date", "Uploaded on that date or later (since: works too).", "") }} {{ op("before:", "date", "Uploaded before that date.", "") }} {{ op("age:", "time", "How old: age:<7d is the last week, age:>1y older than a year. h, d, w, mo, y.", "age:<7d") }}

Order

{{ op("sort:", "how", "new (the default), old, views, favs, comments, long, short, big, small, random, related.", "sort:views") }}

sort:random shuffles the results, the same way on every page of a search, and anew each day.

Go wild

  • {{ ex("type:video duration:<15s sort:views") }}: the most watched videos under fifteen seconds.
  • {{ ex("has:comments comments:>3 sort:comments") }}: where people won't stop talking.
  • {{ ex("-has:tags") }}: f0cks nobody tagged yet. Go and help.
  • {{ ex("rating:untagged") }}: f0cks without a rating.
  • {{ ex("type:gif sort:random") }}: a gif slot machine.
  • {{ ex("favs:0 views:>50") }}: watched a lot, loved by nobody.
  • {{ ex("age:<30d sort:favs") }}: the best of the month.
  • {{ ex("size:>50mb sort:big") }}: the heavyweights.

Above the results F0ckgle says how it read your search, and what it had to leave out.

What search doesn't show

  • Private f0cks, except to the person who uploaded them.
  • Deleted and expired f0cks, and f0cks that aren't available any more.
  • Anything at all if you're not signed in: searching is for members. Sign in
